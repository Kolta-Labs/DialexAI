Remote Connectivity Overview
The Dialex engine daemon is listening and ready to accept connections from Desktop clients, Android/iOS Mobile apps, or CLI automation runners.
Tailscale / Private Mesh (Scenario C)
Recommended for remote access. Connect without port forwarding using your server's Tailscale IP or MagicDNS hostname.
Local LAN Connection
Connect from phones or laptops on the same Wi-Fi using the server's LAN IP address on port 7890.
